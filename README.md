## 📖 About This Repository

Welcome to my personal **Git & GitHub Study Series** repository.

This repository documents my journey of learning **Git** and **GitHub** through structured notes, diagrams, mind maps, practical examples, infographics, and cheat sheets.

The goal of this project is **not** to memorize Git commands, but to understand:

- 🧠 **How Git works internally** (snapshots, commit graphs, references, and objects).
- 💡 **Why each Git command exists** and what problem it solves.
- 🔄 **The three trees / working areas** (Working Directory, Staging Area, and Git Repository).
- 🌿 **Branching and merging dynamics** in both local and remote environments.
- 🐙 **How GitHub fits into modern development** and collaborative workflows.
- 💼 **Professional Git best practices** used in real-world engineering teams.

Whether you're a beginner taking your first steps or someone looking for well-organized revision notes, I hope this repository serves as a valuable, clear reference.

## 🚀 Core Philosophy & Mental Models

Git is often intimidating when taught as a collection of random terminal commands. This series approaches Git through foundational principles:

1. **Snapshots, Not Differences**: Git records snapshots of the entire mini-filesystem over time, not file deltas. Unchanged files are simply linked via lightweight SHA-1 references.
2. **The Three Trees**:

   ```text
   +-------------------+      git add       +------------------+     git commit     +-------------------+
   | Working Directory | -----------------> |  Staging Area    | -----------------> | Git Repository    |
   |   (Local Files)   | <----------------- |     (Index)      |                    | (Commits / HEAD)  |
   +-------------------+    git restore     +------------------+                    +-------------------+
   ```

3. **Branches Are Just Movable Pointers**: A Git branch is merely a 41-byte text file pointing to a specific commit hash. Switching branches simply moves the `HEAD` pointer.
4. **History Safety First**: Understand the difference between safe operations (`git revert`, creating feature branches) and history-rewriting operations (`git reset --hard`, `git push --force`). Never rewrite public shared history!

## 📅 Future Roadmap & Advanced Topics

While the foundational Git and branching documentation is complete, this knowledge base will expand into advanced topics:

- ⚙️ **Git Internals Deep Dive**: Blobs, Trees, Commit objects, Annotated Tags, and packfile compression.
- 🔑 **Authentication & Security**: SSH key generation, Agent forwarding, and GPG commit signing.
- 🔄 **Advanced History Manipulation**: Interactive rebase (`git rebase -i`), `git cherry-pick`, and squash workflows.
- 🕵️ **Debugging History**: `git bisect` (binary searching bugs) and `git blame`.
- 📦 **Git Stash Advanced Features**: Named stashes, branching from stashes, and untracked file handling.
- 🤖 **Automation & Git Hooks**: Client-side hooks (`pre-commit`, `commit-msg`), Husky, and lint-staged setups.
- 🚀 **GitHub CI/CD & Actions**: Automated pull request checks, testing pipelines, and release workflows.
